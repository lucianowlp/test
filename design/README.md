# Receituario Karolayne Marques

Arquivo principal:

- `receituario-karolayne-marques.svg`

## Como editar

Abra o SVG em um editor vetorial, como Inkscape, Illustrator, Affinity Designer ou Figma. Os textos foram mantidos como elementos editaveis, incluindo nome, CRO, campos, assinatura, contatos e endereco.

## Como imprimir

O arquivo esta em tamanho A4 (`210mm x 297mm`) e usa formas vetoriais para manter boa qualidade em impressao. Para enviar para grafica, exporte como PDF mantendo o tamanho A4 e, se necessario, converta fontes em curvas no editor escolhido.
